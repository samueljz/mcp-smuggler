# mcp-cli — Local Docker Setup

A self-contained local [MCP](https://modelcontextprotocol.io/) server, running via Docker, with a one-command setup script for the [`mcp-cli`](https://github.com/philschmid/mcp-cli) tool.

---

## Prerequisites

| Tool | Purpose | Install |
|---|---|---|
| Docker Desktop | Runs the MCP server container | [docker.com](https://www.docker.com/products/docker-desktop) |
| Atlassian API tokens | Authenticate against your Jira/Confluence | [id.atlassian.com](https://id.atlassian.com/manage-profile/security/api-tokens) |
| Figma API token | Authenticate against Figma | [figma.com/settings](https://www.figma.com/settings) |
| Node.js ≥ 18 | Run Figma MCP server via `npx` | [nodejs.org](https://nodejs.org) |
| `curl` | Install `mcp-cli` | pre-installed on macOS/Linux |

---

## Quick Start

### Step 1 — Configure credentials

```bash
cp .env.example .env
```

Open `.env` and replace each placeholder with your real Atlassian credentials. See `.env.example` for all required variables and descriptions.

### Step 2 — Pull the image

```bash
docker pull ghcr.io/sooperset/mcp-atlassian:latest
```

### Step 3 — Start the server

```bash
docker compose up -d
```

Verify the container is running:

```bash
docker compose ps
```

View logs:

```bash
docker compose logs -f
```

## Client Setup (mcp-cli)

Run the provided script to install `mcp-cli` and generate your local `mcp_servers.json` config:

```bash
chmod +x scripts/install-mcp-cli.sh
./scripts/install-mcp-cli.sh
```

The script will:
1. Detect `curl` and `docker` as prerequisites
2. Install `mcp-cli` via the official install script
3. Generate `mcp_servers.json` in the project root pointing to the local Docker-based server
4. Print exact next-step commands

### Connect and validate

```bash
# List all available servers and tools (auto-discovers mcp_servers.json)
mcp-cli

# Inspect the Atlassian MCP server tools and parameters
mcp-cli info mcp-atlassian

# Run a live Jira query
mcp-cli call mcp-atlassian jira_search_issues '{"jql": "assignee = currentUser() ORDER BY updated DESC", "max_results": 3}'

# Inspect the Figma MCP server tools and parameters
mcp-cli info figma

# Run a Figma file structure query
mcp-cli call figma get_file '{"fileKey": "YOUR_FIGMA_FILE_KEY"}'
```

## Configuration Reference

All configuration is injected at runtime via the `.env` file. See [`.env.example`](.env.example) for the full list of variables.

| Variable | Description |
|---|---|
| `JIRA_URL` | Base URL of your Jira instance |
| `JIRA_USERNAME` | Your Atlassian account email |
| `JIRA_API_TOKEN` | Jira personal API token |
| `CONFLUENCE_URL` | Base URL of your Confluence instance |
| `CONFLUENCE_USERNAME` | Your Atlassian account email |
| `CONFLUENCE_API_TOKEN` | Confluence personal API token |
| `FIGMA_API_KEY` | Figma Personal Access Token for design data access |
| `IMAGE_DIR` | Directory where downloaded Figma assets are saved (default: `./images`) |
> **Note**: You can also omit Confluence or Figma variables if you only need a subset of services.

For advanced Docker configuration options (env files, HTTP transport, etc.), see the [MCP Atlassian docs](https://mcp-atlassian.soomiles.com/docs/configuration).

## Troubleshooting

### Container exits immediately
Check that your `.env` file exists and all required variables are set:
```bash
cat .env
```
Inspect the logs for error details:
```bash
docker compose logs
```

### Image is outdated
Pull the latest version:
```bash
docker compose pull
docker compose up -d
```

### `mcp-cli` can't find the server
Make sure `mcp_servers.json` exists in the project root (run `./scripts/install-mcp-cli.sh` if missing). Verify Docker is running and `.env` is present, then run `mcp-cli` from the project root so it auto-discovers the config file.
