# MCPC — Local Docker Setup

A self-contained local [MCP](https://modelcontextprotocol.io/) server, running via Docker, with a one-command setup script for the [`mcpc`](https://github.com/apify/mcpc) CLI client.

---

## Prerequisites

| Tool | Purpose | Install |
|---|---|---|
| Docker Desktop | Runs the MCP server container | [docker.com](https://www.docker.com/products/docker-desktop) |
| Atlassian API tokens | Authenticate against your Jira/Confluence | [id.atlassian.com](https://id.atlassian.com/manage-profile/security/api-tokens) |
| Node.js ≥ 18 or Homebrew | Install `mcpc` | [nodejs.org](https://nodejs.org) / [brew.sh](https://brew.sh) |

---

## Quick Start

### Step 1 — Configure credentials

```bash
cp .env.example .env
```

Open `.env` and replace each placeholder with your real Atlassian credentials. See `.env.example` for all required variables and descriptions.

### Step 2 — Pull the image

```bash
docker pull ghcr.io/sooperset/mcp-atlassian:latest
```

### Step 3 — Start the server

```bash
docker compose up -d
```

Verify the container is running:

```bash
docker compose ps
```

View logs:

```bash
docker compose logs -f
```

---

## Client Setup (mcpc)

Run the provided script to install `mcpc` and generate your local `mcp.json` config:

```bash
chmod +x scripts/install-mcpc.sh
./scripts/install-mcpc.sh
```

The script will:
1. Detect your OS and install `mcpc` via Homebrew (macOS) or npm
2. Generate `mcp.json` in the project root pointing to the local Docker-based server
3. Print exact next-step commands

### Connect and validate

```bash
# Connect mcpc to the server
mcpc connect mcp.json:mcp-atlassian @atlassian

# List available MCP tools
mcpc @atlassian tools-list

# Run a live Jira query
mcpc @atlassian tools-call jira_search_issues '{"jql": "assignee = currentUser() ORDER BY updated DESC", "max_results": 3}'
```

## Configuration Reference

All configuration is injected at runtime via the `.env` file. See [`.env.example`](.env.example) for the full list of variables.

| Variable | Description |
|---|---|
| `JIRA_URL` | Base URL of your Jira instance |
| `JIRA_USERNAME` | Your Atlassian account email |
| `JIRA_API_TOKEN` | Jira personal API token |
| `CONFLUENCE_URL` | Base URL of your Confluence instance |
| `CONFLUENCE_USERNAME` | Your Atlassian account email |
| `CONFLUENCE_API_TOKEN` | Confluence personal API token |

> **Note**: You can omit Confluence variables if you only need Jira (and vice versa). The server enables only the tools whose variables are present.

For advanced Docker configuration options (env files, HTTP transport, etc.), see the [MCP Atlassian docs](https://mcp-atlassian.soomiles.com/docs/configuration).

## Troubleshooting

### Container exits immediately
Check that your `.env` file exists and all required variables are set:
```bash
cat .env
```
Inspect the logs for error details:
```bash
docker compose logs
```

### Image is outdated
Pull the latest version:
```bash
docker compose pull
docker compose up -d
```

### `mcpc` can't connect to the server
Make sure the `mcp.json` file exists in the project root (run `./scripts/install-mcpc.sh` if missing). Verify Docker is running and `.env` is present before connecting.
